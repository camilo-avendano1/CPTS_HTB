### **FTP y TFTP: Protocolo de Transferencia de Archivos**

---

## **FTP (File Transfer Protocol)**

El **Protocolo de Transferencia de Archivos (FTP)** es uno de los protocolos más antiguos en Internet. Funciona dentro de la **capa de aplicación** del modelo **TCP/IP**, al igual que **HTTP** o **POP**. Estos protocolos funcionan con el soporte de navegadores web o clientes de correo electrónico para ofrecer sus servicios. También existen programas específicos diseñados exclusivamente para FTP.

### **Funcionamiento Básico de FTP**

Imaginemos que queremos **subir archivos locales** a un servidor y **descargar otros archivos** utilizando el protocolo FTP. En una conexión FTP, se abren **dos canales**:

1. **Canal de Control (TCP puerto 21)**: Se utiliza para enviar comandos desde el cliente al servidor y recibir códigos de estado.
2. **Canal de Datos (TCP puerto 20)**: Exclusivamente para la transmisión de datos. Si la conexión se interrumpe, la transmisión puede reanudarse tras restablecer el contacto.

### **Modos de FTP**

- **FTP Activo:** El cliente establece una conexión en el **puerto 21**, informando al servidor sobre el puerto cliente donde debe responder. Si el cliente está detrás de un **firewall**, el servidor no puede responder debido a las conexiones bloqueadas.
- **FTP Pasivo:** El servidor informa al cliente sobre un puerto específico para la transmisión de datos. El cliente inicia la conexión al puerto especificado, evitando problemas con el firewall.

### **Comandos y Códigos de Estado**

FTP utiliza una lista de comandos y códigos de estado para operar. Algunos ejemplos son:
#ftp #ftpcommands 
- **LIST:** Listar archivos en el directorio.
- **STOR:** Subir un archivo al servidor.
- **RETR:** Descargar un archivo del servidor.

FTP suele requerir **credenciales de autenticación** para su acceso. Sin embargo, algunos servidores permiten el acceso **anónimo**, lo que implica que cualquier usuario puede conectarse sin necesidad de contraseña.

## **TFTP (Trivial File Transfer Protocol)**

El **Protocolo Trivial de Transferencia de Archivos (TFTP)** es una versión más sencilla de FTP. Está diseñado para transferencias básicas de archivos entre cliente y servidor.

### **Características Clave de TFTP:**

- **Sin autenticación:** No requiere usuario ni contraseña.
- **Protocolo UDP:** Usa **UDP** en lugar de **TCP**, lo que lo hace menos fiable.
- **Limitaciones de acceso:** Opera exclusivamente en directorios y archivos con permisos globales de lectura/escritura.
- **Uso local:** Generalmente se utiliza en **redes locales protegidas** debido a su falta de seguridad.

### **Comandos de TFTP**

|**Comando**|**Descripción**|
|---|---|
|**connect**|Establece la conexión con el host remoto.|
|**get**|Descarga un archivo desde el servidor.|
|**put**|Sube un archivo al servidor.|
|**quit**|Cierra la sesión de TFTP.|
|**status**|Muestra el estado actual de la conexión.|
|**verbose**|Activa/desactiva el modo detallado de transferencia.|

A diferencia de FTP, **TFTP no permite listar directorios**.

## **Configuración Predeterminada de vsFTPd**

Uno de los servidores FTP más utilizados en distribuciones Linux es **vsFTPd**. Su configuración predeterminada se encuentra en:

```bash
/etc/vsftpd.conf
```

Podemos instalarlo con el siguiente comando:

```bash
sudo apt install vsftpd
```

### **Parámetros Clave en vsFTPd**

|**Configuración**|**Descripción**|
|---|---|
|**listen=NO**|¿Correr como un daemon independiente?|
|**anonymous_enable=NO**|¿Permitir acceso anónimo?|
|**local_enable=YES**|¿Permitir inicio de sesión a usuarios locales?|
|**dirmessage_enable=YES**|Mostrar mensajes al entrar en directorios específicos.|
|**use_localtime=YES**|Usar la hora local.|
|**xferlog_enable=YES**|Habilitar registros de transferencia.|
|**secure_chroot_dir=/var/run/vsftpd/empty**|Directorio vacío para chroot.|

---

### **Usuarios Restringidos en FTP**

En el archivo `/etc/ftpusers`, podemos especificar los usuarios que **no tienen permitido acceder al servicio FTP**.

**Ejemplo:**

```text
guest
john
kevin
```

## **Configuraciones Peligrosas en FTP**

Algunos parámetros FTP pueden ser peligrosos si no se configuran correctamente:

|**Configuración**|**Descripción**|
|---|---|
|**anonymous_enable=YES**|Permitir inicio de sesión anónimo.|
|**anon_upload_enable=YES**|Permitir cargas anónimas.|
|**anon_mkdir_write_enable=YES**|Permitir creación de directorios anónimos.|
|**no_anon_password=YES**|No pedir contraseña a usuarios anónimos.|

## **Interacción con FTP**

Podemos interactuar con un servidor FTP anónimo utilizando comandos estándar:

```bash
ftp 10.129.14.136
```

**Comandos Útiles:**

- **ls:** Listar archivos.
- **get :** Descargar un archivo.
- **put :** Subir un archivo.
- **status:** Mostrar el estado de la conexión.

---

## **Exploración de FTP con Nmap**

Nmap es una herramienta poderosa para detectar y analizar servidores FTP. Podemos usarlo con los siguientes comandos:

**Actualizar Scripts de Nmap:**

```bash
sudo nmap --script-updatedb
```

**Escanear un servidor FTP:**

```bash
sudo nmap -sV -p21 -sC -A 10.129.14.136
```

**Algunos scripts específicos para FTP:**

```bash
/usr/share/nmap/scripts/ftp-anon.nse
/usr/share/nmap/scripts/ftp-brute.nse
/usr/share/nmap/scripts/ftp-syst.nse
```

---

## **Interacción con SSL/TLS en FTP**

Si un servidor FTP usa **TLS/SSL**, podemos interactuar usando **OpenSSL**:

```bash
openssl s_client -connect 10.129.14.136:21 -starttls ftp
```

**Ejemplo de Salida del Certificado SSL:**

```
CN = master.inlanefreight.htb
emailAddress = admin@inlanefreight.htb
```

Esto puede revelar **nombres de dominio**, **correos electrónicos administrativos**, y otra información relevante.

---

## **Resumen Clave:**

1. FTP utiliza dos canales (Control y Datos).
2. TFTP es menos seguro y funciona mediante UDP.
3. La configuración de vsFTPd debe ajustarse cuidadosamente.
4. El acceso anónimo FTP puede exponer archivos sensibles.
5. Herramientas como **Nmap** y **OpenSSL** son esenciales para la enumeración de servidores FTP.
6. Es fundamental evitar configuraciones peligrosas en FTP, como el acceso anónimo abierto.

FTP puede ser un punto de entrada valioso durante una prueba de penetración si no está configurado adecuadamente.
