### **SMB (Server Message Block)**

El protocolo **Server Message Block (SMB)** es un protocolo cliente-servidor que regula el acceso a **archivos**, **directorios completos** y otros recursos de red, como **impresoras**, **enrutadores** o **interfaces** compartidas en la red. También puede manejar el **intercambio de información** entre diferentes procesos del sistema.

---

## **Funcionamiento de SMB**

El protocolo **SMB** permite que un cliente se comunique con otros participantes en la misma red para acceder a **archivos** o **servicios** compartidos. El sistema remoto debe tener implementado SMB y procesar las solicitudes del cliente mediante una **aplicación de servidor SMB**.

- SMB utiliza **TCP/IP** para la transmisión de datos, con un **handshake de tres vías** entre el cliente y el servidor antes de establecer la conexión.

### **Permisos en SMB**

- **Listas de Control de Acceso (ACL):** Controlan permisos como **ejecución**, **lectura** y **acceso completo** para usuarios individuales o grupos.
- Los permisos ACL son **independientes** de los permisos locales del servidor.

---

## **Samba**

**Samba** es una implementación gratuita de SMB para **Linux** y **Unix**. Implementa el protocolo **Common Internet File System (CIFS)**, que es una variante de **SMB versión 1**.

### **Versiones de SMB**

| **Versión SMB** | **Soportado en** | **Características**                      |
| --------------- | ---------------- | ---------------------------------------- |
| **CIFS**        | Windows NT 4.0   | Comunicación vía NetBIOS                 |
| **SMB 1.0**     | Windows 2000     | Conexión directa TCP                     |
| **SMB 2.0**     | Windows Vista    | Mejora de rendimiento, firma de mensajes |
| **SMB 2.1**     | Windows 7        | Mecanismos de bloqueo                    |
| **SMB 3.0**     | Windows 8        | Conexiones multicanal, cifrado           |
| **SMB 3.1.1**   | Windows 10       | Integridad de datos, cifrado AES-128     |

Con Samba versión **3.0**, el servidor puede ser miembro de un **Active Directory**. Desde la versión **4.0**, Samba puede actuar como un **controlador de dominio Active Directory**.

### **Configuración Predeterminada**

La configuración predeterminada de Samba se almacena en `/etc/samba/smb.conf`.

**Ejemplo de configuración predeterminada:**

```bash
ougicami@htb[/htb]$ cat /etc/samba/smb.conf | grep -v "#\|\;" 

[global]
   workgroup = DEV.INFREIGHT.HTB
   server string = DEVSMB
   log file = /var/log/samba/log.%m
   max log size = 1000
   logging = file
   panic action = /usr/share/samba/panic-action %d

   server role = standalone server
   obey pam restrictions = yes
   unix password sync = yes

   passwd program = /usr/bin/passwd %u
   passwd chat = *Enter\snew\s*\spassword:* %n\n *Retype\snew\s*\spassword:* %n\n *password\supdated\ssuccessfully* .

   pam password change = yes
   map to guest = bad user
   usershare allow guests = yes

[printers]
   comment = All Printers
   browseable = no
   path = /var/spool/samba
   printable = yes
   guest ok = no
   read only = yes
   create mask = 0700

[print$]
   comment = Printer Drivers
   path = /var/lib/samba/printers
   browseable = yes
   read only = yes
   guest ok = no
```

---

## **Parámetros Importantes en Samba**

|**Configuración**|**Descripción**|
|---|---|
|**workgroup = WORKGROUP**|Nombre del grupo de trabajo.|
|**path = /ruta**|Directorio compartido.|
|**unix password sync = yes**|Sincronizar contraseñas UNIX con SMB.|
|**guest ok = yes**|Permitir acceso sin contraseña.|
|**browseable = yes**|Mostrar el recurso en la lista de recursos compartidos.|
|**read only = yes**|Permitir solo lectura.|
|**writable = yes**|Permitir escritura.|
|**create mask = 0777**|Permisos para archivos nuevos.|
|**directory mask = 0777**|Permisos para directorios nuevos.|

## **Configuración de un Recurso Compartido Inseguro**

```bash
[notes]
   comment = CheckIT
   path = /mnt/notes/
   browseable = yes
   read only = no
   writable = yes
   guest ok = yes
   enable privileges = yes
   create mask = 0777
   directory mask = 0777
```

Reiniciar el servicio después de editar la configuración:

```bash
root@samba:~# sudo systemctl restart smbd
```
